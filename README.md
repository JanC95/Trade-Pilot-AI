# TradePilot AI automated preview
Deploy this folder to Vercel (Node serverless functions). Configure server environment variables OPENAI_API_KEY (new key), TWELVE_DATA_API_KEY, TRADEPILOT_ACCESS_TOKEN (strong private preview password), optional OPENAI_MODEL and TRADING_ECONOMICS_KEY. Redeploy. Clients select symbol and timeframe; only the preview password is requested once per browser session. No market inputs. Provider plans must support selected symbols, intervals and redistribution; index mappings may need adjustment. News is optional and failures are explicitly reported; no continuous monitoring. Closed/stale markets return errors. Dashboard/watchlist remain demo. RSI/ATR use simple rolling averages, EMA uses first-close seed. Candidate levels use trend agreement and ATR/swing risk, not a backtested strategy. The AI can reject candidates; chart shows candidates only. Private preview only: production authentication, quotas, billing, data licensing and testing are required. No secrets included. No automatic orders.

Real-data-only edition: dashboard and watchlist no longer show sample quotes or charts. Select Analyse Market to fetch actual completed candles. No data is shown if the provider is unavailable. Dashboard quotes are not streamed. Historical reports from earlier demo versions are not imported. Configure a replacement OpenAI key and a Twelve Data key; OpenAI alone cannot supply a reliable price feed. Provider entitlement and delays must be checked before commercial use.
