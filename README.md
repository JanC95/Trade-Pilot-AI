# TradePilot AI
Open index.html for local demo. For deployment, import this folder as a Git repository into Vercel (or use Vercel CLI). Select Other framework, no build command. Set server environment variables OPENAI_API_KEY (new key), OPENAI_MODEL (optional), TRADEPILOT_ACCESS_TOKEN (strong random private preview password). Deploy and use the assigned subdomain. Verify hosting plan permits your intended commercial use. Never publish secrets. The preview token is not production authentication; add per-user authentication, rate limits and quotas before public AI access. Market and news snapshots are manually supplied; no live feed or automatic monitoring. Charts are illustrative. Local storage is not a cloud database. Billing disabled. No backtesting or live API testing performed.
